## 本轮做了什么

### 1. 绕过 PMGR 守卫，直接验证 root 路径

上游 `scripts/unixnu/payload.py` 里有两道守卫，禁止在没有 PMGR 的情况下用 `native-ufs-root=1`：

```python
raise Error('native UFS root boot needs exactly one sheng-pmgr=2; ...')
raise Error('the native UFS root kernel lacks the linked sheng PMGR integration')
```

本地把它们降级成警告（仅实验用，未提交），然后：

```
native-ufs-root=1            # 真正的 root 发布路径
amfi_get_out_of_my_way=1     # 尝试让 AMFI 放行
sheng-smp=1  armcpu-spi-ipi=1  cpus=1
```

### 2. 结果：根卷挂上了，AMFI 仍然拦

开机后先像以前一样停在 UFS 相关画面，**10–20 秒后继续往下走**，最终显示：

```
stage: pid0  PE_lockdown:kit → kernel_task: bed_init → bed_autoconf → loopattach
             → ether_family_init → net_init_run → initthrd → setcon
"AMFI: No PMGR?\n" @ConfigurationSettings.cpp:235
```

**这是本阶段最重要的结果**：

- `native-ufs-root=1` 路径工作 —— 根设备发布、根卷挂载成功
- 内核初始化基本完成（`initthrd` / `setcon` 已在 `bsd_init` 后期）
- `amfi_get_out_of_my_way=1` **不能**绕过这个检查（它不是信任校验，而是平台服务依赖）

### 3. AMFI 到底要什么（反汇编结论）

`AppleMobileFileIntegrity.kext` 里的代码：

```
ApplePMGRNub                          ← IONameMatch
AMFI: PMGRAON latched to: %x          ← 读到的 AON 值
"AMFI: No PMGR?\n" @%s:%d             ← 服务不存在时的 panic
```

即：`waitForMatchingService("ApplePMGRNub")` 失败就 panic。
所以需要的不是"完整的电源管理"，而是**一个能应答的 `ApplePMGRNub` 服务**。

### 4. PMGR 集成的审计通过了

上游 sheng 的做法（`package/ShengPlatformPower.cpp`）：

1. `OSKextLoadKextWithIdentifier("com.apple.driver.ApplePMGR")`
2. 查 `ApplePMGR` / `ApplePMGRNub` 两个 metaclass
3. `new ShengPlatformPower`（继承 Apple 的 `ApplePMGR`，每个虚槽都被 guard）
4. 用 Apple 的工厂函数创建 nub，attach / start / register
5. `waitForMatchingService("ApplePMGRNub")` 自检

生成器 `build-sheng-platform-power.py` 需要一份"参考候选内核"做 ABI 校验。
我们用**自己的预链接内核**顶替，并补上它要的 `kernel.json` 与原始 kernelcache，审计通过：

```
PASS: unchanged AMFI read/OR/write and original PMGR provider dispatch
PASS: actual target AppleT8011PMGR slots read 0xffffffff and perform no write
Static evidence only; native platform service integration remains unresolved
```

**含义**：我们的内核与 sheng 的 AMFI/PMGR 布局一致（`com.apple.driver.ApplePMGR`
的 `__TEXT_EXEC` 哈希都是 `2c433279…`），所以那份 ABI 生成器对我们同样成立。
